# Agent Terminal

An AI coding-agent CLI running on the Home Assistant host, with a persistent
login, a mobile-friendly web terminal, SSH, and a built-in Home Assistant MCP
server. Switch Claude Code, ChatGPT via OpenAI Codex, and Shell with buttons
or Ctrl+Shift+1 / 2 / 3. Task workspaces have their own live sessions, folders,
instructions, and skills. Create named sessions of the same provider, find them
with **Sessions** or **Ctrl+Shift+K**, and open two side by side on a wide screen.
Paste a screenshot, drop a file, or pick a photo on your phone to hand it to the agent.
Each agent keeps its login. See [DOCS.md](DOCS.md)
for setup, options, and the security caveats -
read that before installing.
