# Agent Terminal

An AI coding-agent CLI running on the Home Assistant host, with a persistent
login, a mobile-friendly web terminal, SSH, and a built-in Home Assistant MCP
server. Choose Claude Code (`agent: claude`) or ChatGPT via OpenAI Codex
(`agent: codex`), each with its own persistent login. See [DOCS.md](DOCS.md)
for setup, options, and the security caveats -
read that before installing.
